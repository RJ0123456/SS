# Multi-Agent System for Video Production

## Information Gathering Agent

### Daily sourcing of trending news (especially AI-related)

Regularly gather information from major online platforms and channels.

Includes:

1. Source information
2. Summary
3. Visuals (images/graphics) or video
4. Compiling collected information into a Markdown document and emailing it (email address is configurable)

**Note**: News items selected daily must meet these criteria:

1. General public interest/trending topics
2. Industry-specific hot topics/areas of focus
3. High-potential stories
4. Limited volume (maximum of 30 items)

## Preparing the content

Note: This stage involves manual review and falls outside the agent's automated logic.

1. Review the information
2. Comprehend the content
3. Select valuable news items

## Conent Generation Agent

### Script Generation

1. Select news items
2. Run the agent to generate the video script
Note: Supports prompt input (e.g., "script must be engaging to the audience")

### Video editing

1. Film on-camera commentary explaining these news events
2. Trim redundant or erroneous footage
3. Enhance visuals (video, images, etc.)
4. Add text/graphics
5. Integrate video clips
6. Add subtitles

### Publishing the video

1. Publish to WeChat Channels
2. Publish to Douyin
3. Publish to Bilibili
